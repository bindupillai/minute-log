# Minute Log

A simple installable web app/PWA for iPhone 11 and newer.

## What it does
- Shows the current time.
- One-tap logging for common activities.
- Automatically records the exact time.
- Shows today's timeline.
- Lets you add custom activities.
- Lets you delete individual entries or clear today's entries.
- Stores data locally on the device/browser.

## Files
- index.html — app screen
- style.css — iPhone-friendly design
- app.js — logging and storage logic
- manifest.json — installable-app settings

## To use on iPhone
The files need to be hosted over HTTPS. A simple free option is GitHub Pages.
Open the site in Safari, then use Share → Add to Home Screen.

Note: this starter version stores data locally. It does not yet sync between devices or back up to the cloud.
